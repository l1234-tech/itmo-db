## Формат новых работ

Для каждой следующей работы создаётся директория lab-N со следующими файлами:
- исходные материалы и сдаваемый отчёт;
- condition.md — условие задания;
- solution.md — текстовая версия решения с объяснением и SQL-кодом.

Для PDF и DOCX оригиналы сохраняются отдельно от Markdown-версии, чтобы отчёт и редактируемое решение не заменяли друг друга.
