# Условие лабораторной работы № 3

**Вариант:** 6543  
**Дисциплина:** Базы данных  
**СУБД:** PostgreSQL

## Задание

Для отношений, полученных при построении предметной области из лабораторной работы № 1, выполнить следующие действия:

1. Описать функциональные зависимости для отношений полученной схемы (минимальное множество).
2. Привести отношения к 3NF (как минимум).
3. Описать изменения в функциональных зависимостях, произошедшие после преобразования в 3NF (как минимум). Построить схему на основе 3NF.
4. Преобразовать отношения в BCNF. Доказать, что полученные отношения представлены в BCNF. Если схема уже находится в BCNF, доказать это.
5. Определить, какие денормализации будут полезны для схемы, и подробно их описать.

Придумать триггер и связанную с ним функцию, относящиеся к предметной области, согласовать их с преподавателем и реализовать на языке PL/pgSQL.

## Требования к отчёту

Отчёт должен содержать:

1. Текст задания.
2. Исходную, нормализованную и денормализованную модели.
3. Ответы на вопросы, представленные в задании.
4. Функцию и триггер на языке PL/pgSQL.
5. Выводы по работе.

## Темы для подготовки к защите

1. Нормализация и нормальные формы.
2. Функциональные зависимости и их виды.
3. Денормализация.
4. Язык PL/pgSQL.
