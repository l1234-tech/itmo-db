# Рубежная работа № 1 — условие

**Дисциплина:** Базы данных  
**СУБД:** PostgreSQL

## Задание

### 1. Инфологическая модель

На основании предметной области из своего варианта описать инфологическую модель. В модели должно быть не менее 8 сущностей и обязательно должна присутствовать связь вида «многие-ко-многим».

В ответе необходимо указать:
- названия сущностей;
- основные атрибуты сущностей;
- между какими сущностями существует связь M:N.

Рисовать ER-модель для этого пункта не требуется.

### 2. Логическая модель

На основании инфологической модели построить логическую модель базы данных.

Требования:
- таблицы должны соответствовать третьей нормальной форме (3NF);
- в качестве СУБД используется PostgreSQL;
- связи между сущностями должны быть отражены первичными и внешними ключами.

### 3. Реализация связи M:N

На основании логической модели описать с помощью DDL таблицы, которые соединены связью «многие-ко-многим», и реализовать эту связь в PostgreSQL.

Нужно создать обе основные таблицы и таблицу-связку с соответствующими первичными и внешними ключами.

### 4. Запрос по предметной области

Сформулировать практическую задачу, для решения которой требуется запрос с указанной конструкцией:
- для **чётных вариантов** — оператор `ALL`;
- для **нечётных вариантов** — `INNER JOIN`.

В ответе привести формулировку задачи и SQL-запрос для её решения. Задача должна иметь практический смысл в рамках выбранной предметной области.

## Материалы к разобранному варианту

В приложенном файле разобран **вариант 9 — «Управление общежитием»**. Рукописное решение содержит восемь основных сущностей и таблицу-связку для отношений «Жители — Мероприятия». Поскольку вариант 9 нечётный, в четвёртом задании используется `INNER JOIN`.
